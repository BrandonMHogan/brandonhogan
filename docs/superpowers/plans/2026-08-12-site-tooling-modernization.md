# Site Tooling Modernization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert the existing static profile page to a framework-free Vite and TypeScript project that runs locally without changing its visual design.

**Architecture:** Vite serves `index.html` directly and bundles a single ES-module TypeScript entry point. The existing stylesheet and image remain the visual baseline; legacy JavaScript libraries are removed because the current page only needs one small DOM interaction.

**Tech Stack:** HTML5, existing CSS, vanilla TypeScript, Vite, npm

## Global Constraints

- Preserve the current content and visual design except for compatibility and accessibility corrections.
- Do not add React or another UI framework.
- Do not add portfolio content or revive the commented gallery.
- Use the latest stable Vite and TypeScript releases resolved into the npm lockfile.
- Require a Node.js version supported by the installed Vite release.

---

## File Structure

- Create `package.json`: npm metadata, scripts, engine requirement, and development dependencies.
- Create `package-lock.json`: reproducible dependency resolution generated by npm.
- Create `tsconfig.json`: strict browser TypeScript checking without a separate emit step.
- Create `src/main.ts`: framework-free avatar interaction.
- Modify `index.html`: semantic HTML5 structure, accurate accessible names, stylesheet link, and ES-module entry point.
- Modify `assets/css/main.css`: retain the design while switching the font import to HTTPS and removing rules that only supported the deleted loading script.
- Modify `README.md`: supported runtime and local development commands.
- Delete `assets/js/main.js`, `assets/js/jquery.min.js`, `assets/js/jquery.poptrox.min.js`, and `assets/js/skel.min.js`: obsolete runtime code.

**Interfaces:**

- Produces: an npm project whose `dev`, `build`, and `preview` scripts invoke Vite; `src/main.ts` safely attaches the avatar click handler.

- [ ] **Step 1: Record the unsupported starting state**

Run: `npm run build`

Expected: FAIL because the repository has no `package.json` and no build script.

- [ ] **Step 2: Add npm and TypeScript configuration**

Create `package.json` with `private: true`, `type: "module"`, scripts `dev: "vite"`, `build: "tsc --noEmit && vite build"`, and `preview: "vite preview"`; declare the latest stable `vite` and `typescript` as development dependencies and the installed Vite release's supported Node.js floor in `engines.node`.

Create `tsconfig.json` with `target: "ES2022"`, `useDefineForClassFields: true`, `module: "ESNext"`, `lib: ["ES2022", "DOM", "DOM.Iterable"]`, `skipLibCheck: true`, `moduleResolution: "bundler"`, `allowImportingTsExtensions: true`, `verbatimModuleSyntax: true`, `moduleDetection: "force"`, `noEmit: true`, and `strict: true`; include `src`.

Run: `npm install --save-dev vite@latest typescript@latest`

Expected: PASS and generate `package-lock.json` with exact dependency versions.

- [ ] **Step 3: Port the only active interaction to TypeScript**

Create `src/main.ts`:

```ts
const avatar = document.querySelector<HTMLElement>(".avatar");

avatar?.addEventListener("click", () => {
  avatar.classList.toggle("spin");
});
```

- [ ] **Step 4: Modernize the active document wiring without redesigning it**

Change the doctype to `<!doctype html>`, add `lang="en"`, use a semantic `main` around the primary introduction, give the portrait descriptive alt text, correct the GitHub and LinkedIn accessible labels, close the footer paragraph, and replace all four legacy scripts with `<script type="module" src="/src/main.ts"></script>`. Remove the large commented gallery and link blocks because they are not part of the active page.

Change the Google Fonts import in `assets/css/main.css` from HTTP to HTTPS. Remove only `.is-loading` rules made unreachable by deleting the old loading script; preserve layout, color, typography, and animation rules.

Delete the four obsolete files under `assets/js/`.

- [ ] **Step 5: Build the modern application**

Run: `npm run build`

Expected: PASS; TypeScript reports no errors and Vite creates `dist/index.html` plus bundled assets.

- [ ] **Step 6: Commit the application upgrade**

```bash
git add package.json package-lock.json tsconfig.json src/main.ts index.html assets/css/main.css assets/js
git commit -m "build: modernize site tooling"
```
